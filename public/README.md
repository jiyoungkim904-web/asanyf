## hero-preview.jpg

랜딩 히어로의 "콘텐츠 미리보기" 핸드폰 목업에 들어가는 이미지입니다.

- **이 폴더에 `hero-preview.jpg` 라는 이름으로 저장**하면 자동으로 표시됩니다.
- 권장 비율: 가로형 16:10 (예: 1280×800). 세로형도 표시되지만 위아래가 잘릴 수 있습니다.
- 파일이 없으면 자연 배경 + 🍐 플레이스홀더로 대체됩니다. (에러 없음)

바꾸려면 같은 이름으로 덮어쓰고 브라우저를 새로고침하세요.
